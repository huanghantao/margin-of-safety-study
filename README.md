# 📖 读懂《安全边际》：一份十二周的中文导读

> 这是一套**专为投资零基础读者**定制的手把手教程。
>
> **主线教材**：塞思·卡拉曼《安全边际》（Margin of Safety）——
> 价值投资圈里"最难买到的那本书"，也是唯一一本把"**怎么才能不亏钱**"
> 当作全书主题的投资书。
>
> **适合谁：** 从没买过股票、没买过基金，PE、PB、ROE 只听人说过但说不清是什么意思，
> 数学只有初中水平，也不打算写代码——但想把"投资"这件事认真搞懂的人。
>
> **承诺：** 每个概念都从 0 讲透。不需要任何先修课程，不需要会看财报，
> 不需要会写代码。你只需要一支笔、一张纸，和一个愿意慢慢来的下午。

## 🤔 这门课和"自己啃原书"有什么区别？

《安全边际》出版于 1991 年，早已绝版，二手价被炒到上千美元。它难读，但不是因为它写得深奥——
而是因为它**默认你已经是圈内人**：默认你知道什么是债券、知道怎么看财报、
知道 1980 年代美国的垃圾债危机是怎么回事。这门课反过来为你做了五件事：

- **零基础补课**：Week 1 和 Week 2 专门用两周，从"股票到底是什么"讲到
  "一家公司怎么估值"，之后原书的任何术语都不会再吓到你（原书默认你会，我们不默认）；
- **时代翻译**：原书的垃圾债、杠杆收购、储贷机构危机全部标注"当年发生了什么"，
  并给出 A股/港股 的当代表达（高收益陷阱、商誉暴雷、更名重组……）；
- **数学降级**：贴现、复利、估值全部改成"一年一年往后乘"的表格，
  只用四则运算和百分比就能手算，不出现任何求和符号、微积分、概率统计；
- **看图学习**：所有涉及精确比例、坐标、结构的图都是脚本生成的 PNG，
  不用会变形的 ASCII 图（想改图就改 `figures/` 里的脚本重跑）；
- **每章都有练习**：想一想（动脑）、算一算（纸笔）、小测验（选择题带解析），
  每周还有一份去真实公司查资料的动手作业。

## 📖 怎么用这套教程

本教程就是本仓库，四个目录各司其职：

```
margin-of-safety-study/（仓库根）
├── learning-guide/   ← 教程正文（你正在看的）
├── figures/          ← 所有配图的生图脚本 + 生成好的图片
├── scripts/          ← 检查工具（LaTeX 规范、交付验收）
├── raw/              ← 原书全文的 markdown（按页拆分，方便对照原始页码）
└── CURRICULUM.md     ← 课程总纲与写作说明书（读者可略过）
```

1. **按顺序读，别跳。** 每周都依赖前面。
2. **边读边对照原书。** 每章末尾的「📖 回到原书」给出对应页码和精读/略读建议；
3. **每章做「✍️ 想一想」和「✅ 小测验」。** 涉及数字的章节请真的拿笔算一遍——
   看别人算一遍和自己算一遍，效果差十倍；
4. **每周做一次「🔍 动手作业」。** 去巨潮资讯网或披露易翻一家真公司的公开文件，
   这是这门课唯一"必须动手"的部分；
5. **看图不爽？** 改 `figures/gen_w*.py` 里的数字重新运行即可。

> 🖼️ 关于图片：所有涉及精确坐标的图都是**脚本生成的 PNG**（在 `figures/out/` 里）。
> 生成时会自动检测"文字压文字、线条穿文字"，但最终仍以你眼睛看到的为准。

## ✅ 学完你会得到什么

- **一套完整的"防亏钱"框架**：先看清别人怎么亏（Week 3–6），再建立自己的哲学（Week 7–9），
  最后落到具体的机会类型和组合管理（Week 10–12）；
- **一个你自己的估值流程**：知道一家公司可以从哪三个角度估值、各自什么时候用、
  以及为什么必须打折；
- **一份可打印的买入前检查清单**：买之前逐项打勾，把"我是不是在骗自己"变成可执行的流程；
- **读懂 A股/港股 年报的入门能力**：知道看哪几张表、警惕哪些科目、去哪里查原始文件；
- **一套情绪应对方案**：市场下跌、被套、别人都在赚钱时，具体该做什么、不该做什么。

## 🧭 常用命令速查

```bash
# 安装依赖（仅生图脚本需要，读者不写代码）
pip install -r requirements.txt

# 重新生成所有配图（改过 figures/ 里的脚本后）
python3 figures/gen_all.py

# 只重跑某一周
python3 figures/gen_all.py w7

# 从 PDF 重建原书 markdown（raw/ 目录）
python3 scripts/pdf_to_pages.py "原书.pdf" "raw/安全边际-中文版"

# 交付验收（一条命令跑完八项：结构 / 标题一致性 / 练习 / 图片 / 生图脚本 / LaTeX / 引文 / mdbook 构建）
python3 scripts/verify_course.py

# 只做引文保真度检查：教程里标注了页码的「原书金句」是否真能在那一页逐字找到
# （verify_course.py 已经包含这一步，单独跑便于只看引文）
python3 scripts/verify_quotes.py

# 构建网页版教程
mdbook build && mdbook serve --open
```
