# Week 2 导读：估值入门——一家公司值多少钱

Week 1 里你已经知道：买股票就是买下一家公司的一小片，而它的价格每天在跳。
可是价格跳来跳去，总得有个参照物——**这家公司到底值多少钱？**

这一周就来解决这个问题。

先说清楚一件事，免得你以为自己漏学了什么：原书《安全边际》是写给**已经懂财务报表和估值**的读者的。
卡拉曼在第八章一上来就讲"现值分析法""清算价值""私有市场价值法"，好像这些都是常识。
但对第一次接触投资的人来说，那是一堵墙。

所以我们把这一周做成**补课周**：把"看懂一家公司值多少钱"所需要的最小知识集，从头讲一遍。
这一周的内容是**原创的**，原书里没有对应章节；原书第八章（企业评估艺术）要到 **Week 9** 才正式讲。
本周的任务只有两个字：**够用**。

- 只讲**三个数字**：它有什么、它一年赚多少、它真收到多少钱。
- 只讲**四个倍数**：市盈率、市净率、净资产收益率、股息率。
- 只讲**一种数学**：今天的 100 元不等于明年的 100 元。
- 第 5 章让**安全边际**先露个面，点到为止，Week 7 会正式讲透。

学完这一周，你不会变成分析师。但你会拥有一件这个市场上很多参与者都没有的东西：
**一套自己动手算、而不是听别人说的估值方法。**

## 🎯 学完你会得到什么

1. **能分清事实与猜测。** 拿到一家公司，你能立刻说出：哪些数字可以翻年报查证，哪些只是某人的估计。
2. **能看懂三个数字。** 打开一份年报，你知道去"合并资产负债表""合并利润表""合并现金流量表"里各找一个数：净资产、净利润、经营现金流。
3. **能手算四个倍数。** 给你股价、每股盈利、每股净资产、每股分红，你能在纸上算出市盈率、市净率、ROE 和股息率，并说出每个数在回答什么问题。
4. **能自己算一遍贴现。** 不借助任何工具，你能把三年后的 121 元换算成今天的钱，并解释为什么未来的钱更不值钱。
5. **能用三种方法给同一家公司估一个区间。** 你会得到三个不同的数字，并且知道该拿哪一个当底线。
6. **知道"打折买入"是怎么保护你的。** 你能画出"买入价—保守估值—乐观估值"这条线，说出自己最多能错多少还不亏。
7. **这对你的钱包意味着什么：** 从此以后，你看到一只股票的第一反应不再是"它会涨吗"，而是"它大概值多少、现在这个价打了折没有"。这一个问题的替换，就已经让你和大多数买入者站在了不同的位置上。

## 🔍 动手作业

这一周的作业只有一个：**去下载一份真实的年报，并在里面找到四个数字。**

不用怕，年报有 200 到 400 页，但我们不去读它——我们只做"搜索 + 抄数字"。

**去哪里查**

- 打开**巨潮资讯网**（中国证监会指定的上市公司信息披露网站）：`www.cninfo.com.cn`
- 在搜索框里输入一家公司的代码或名字。建议从这三家里挑一家，它们生意简单、报表好懂：
  - 贵州茅台 `600519`
  - 长江电力 `600900`
  - 福耀玻璃 `600660`
- 进入公司页面后，点「**公告**」，在公告类型里筛选「**年报**」（有的页面写作「定期报告 → 年度报告」）。
- 下载**最近一份年度报告**的 PDF。（想练港股的，可以去**港交所披露易** `www.hkexnews.hk`，找「Annual Report」，流程一样。）

**查什么、记什么**

打开 PDF，用搜索功能（Windows 是 `Ctrl+F`，Mac 是 `Command+F`），依次搜下面四个词。
每找到一个，就把**数字**和**单位**一起抄在纸上：

1. 搜「**货币资金**」——在「合并资产负债表」里。
2. 搜「**归属于母公司股东的净利润**」——在「合并利润表」或前面的「主要会计数据」一节里。
3. 搜「**经营活动产生的现金流量净额**」——在「合并现金流量表」里。
4. 搜「**每 10 股派**」或「**利润分配**」——在「利润分配方案」一节里，记下"每 10 股派现金 X 元"。

**回答这几个问题**

1. 这家公司账上的货币资金是多少？把它和它一年的净利润比一比，是更多还是更少？
2. 去年净利润、经营活动现金流净额分别是多少？哪个更大？
3. 如果经营现金流比净利润小很多，你觉得钱去哪儿了？（提示：去资产负债表里看看"应收账款"和"存货"是不是变多了。）
4. 把"每 10 股派 X 元"换算成**每股分红**（除以 10），再除以你查到的股价，算出**股息率**大约是多少？
5. 用「净利润 除以 净资产」算一下 **ROE** 大约是多少？（净资产在资产负债表里找「归属于母公司股东的权益」或「所有者权益合计」。）

**参考答案与判断标准**

- **数字本身每年都在变，所以这里不给标准数字，只给"你有没有找对"的判断标准：**
  - 你抄下来的数应该是"亿元"或"万元"级别的量级，而不是几百、几千。如果算出来的 ROE 是 300%，或者货币资金只有 50 万元，那八成是看错了行，或者没注意单位——有的公司用「元」，有的用「千元」，有的用「百万元」，**单位就写在每一张表的表头右上角**。
  - 一个量级参考：像茅台这样的公司，账上的货币资金长期是**几百亿元级别**的（具体数字每年都在变，这里只是给你一个"有没有找错行"的对照）。如果你查到的只有几亿元，回去重新找。
  - 问题 2 的答案通常是：**长江电力这类重资产公司，经营现金流往往明显大于净利润**，因为它每年的折旧金额很大，而折旧是不用掏现金的（第 1 章会讲）。福耀玻璃是制造业，资本开支大，经营现金流和净利润的差距会更小一些。
  - 问题 3 的判断标准：如果应收账款大幅增加，说明东西卖出去了但钱还没收回来；如果存货大幅增加，说明货压在仓库里。这两种都会让"账面利润"比"到手现金"漂亮。
  - 问题 4、5 只要你能算出 4% 或 15% 这样"看着合理"的百分比，并且说得清分子分母分别是什么，就算过关。
- **加分项**：把这份年报的「合并资产负债表」抄下来，用第 1 章的恒等式检查一遍——「资产 = 负债 + 所有者权益」，两边要是对不上，说明你抄漏了行。

## 📖 本周术语表

本周新出现的词（后面几周还会一直用，口径不会变）：

| 术语 | 一句话解释 | 生活里的类比 |
|---|---|---|
| 估值 | 估算一家公司值多少钱这件事 | 给二手房估价 |
| 内在价值 | 一家公司**真正**值多少钱，由它的资产、盈利、现金流决定，而不是由股价决定 | 房子的实际居住价值，不是挂牌价 |
| 财务报表 | 公司定期公布的记账结果，主要是三张表 | 体检报告 |
| 资产 / 负债 / 净资产 | 它有什么 / 它欠什么 / 扣掉欠的之后真正属于股东的部分 | 家当 / 外债 / 净身家 |
| 账面价值 | 会计账本上记的净资产：总资产减总负债 | 账本上的家底 |
| 净利润 | 一年做生意的收入，扣掉所有成本费用和税之后剩下的钱 | 一个月工资扣掉开销后的结余 |
| 每股盈利 | 净利润除以总股本，摊到每一股上是多少钱 | 一家人平摊一笔收入 |
| 经营现金流 | 主业一年真正收进来、付出去的现金净额 | 银行流水里"干活挣的净额" |
| 资本开支 | 为了维持生意必须花掉的买设备、建厂的钱 | 装修店面、换冰箱 |
| 自由现金流 | 经营现金流减去资本开支，真正能自由支配的钱 | 工资减去必须开销后能自由花的钱 |
| 折旧 | 设备厂房一年磨损掉的价值，它记在成本里但不用掏现金 | 手机用一年就不值原价了 |
| 市盈率（P/E） | 股价除以每股每年赚的钱，粗略理解为"多少年赚回本金" | 买个铺子几年回本 |
| 市净率（P/B） | 股价除以每股对应的账面净资产 | 花 8 毛钱买账本上 1 元的家当 |
| 净资产收益率（ROE） | 公司用股东的钱一年赚出了百分之几的回报 | 投 100 元本钱，一年赚回多少 |
| 股息率 | 一年分红除以股价 | 房租除以房价 |
| 复利 | 利息也会生利息，一年一年滚下去 | 存钱罐里的钱自己长大 |
| 贴现（折现）/ 现值 | 把未来的钱换算成"相当于今天的多少钱" | 明年的 110 元 = 今天的 100 元 |
| 贴现率 | 你要求的年回报率，用来把未来的钱折回今天 | 你心里的最低收益率 |
| 清算价值 | 公司今天就关门、资产一件件卖掉还完债后剩下的钱 | 二手甩卖价 |
| 安全边际 | 买入价与保守估算的价值之间的差距，是你为自己估错留出的容错空间 | 桥限重 3 万磅，只让 1 万磅的车过 |
