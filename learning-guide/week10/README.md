# 本周导读

> 这是 Week 10。上一周（Week 9）我们把"怎么给一家公司估值"这门手艺做完了：
> 价值是一个范围、现值分析法、贴现率怎么选、清算价值、股市价值法，
> 最后还完整走了一遍 Esco 电子公司的评估实例。
> **到这里，你已经会回答"它值多少钱"了。**
>
> 可是紧接着就是一个更实际的问题：**这样算出来的便宜货，到底去哪里找？**
> 你不可能把 A 股五千多家、港股两千多家公司一家一家算一遍。
> 这一周，卡拉曼把答案拆成了三张地图：三类缝隙、一个反直觉的姿态（逆向）、
> 一条别人懒得看的线索（内部人买入）、一个点火器（催化剂），以及六种具体的机会。

---

## 为什么要有这一周

先看你现在的处境。

假设你已经完全学会了 Week 9 的功夫。你花三个晚上研究了一家公司，算出它每股大约值 100 元，现在的股价是 60 元，折扣 40%，看起来很划算。

然后你抬起头，发现一个问题：**这样的公司，你是怎么找到它的？**

如果答案是"朋友说的""软件推的""刷视频刷到的"，那你前面九周学的所有东西，都建立在一个你自己无法控制的入口上。**找错了地方，再好的估值手艺也没用**——因为你算的全是那些价格已经充分反映价值的公司（原书 p163 说的正是这件事），算得再准，也只是确认了"它不便宜"。

这一周要解决的，就是"入口"的问题。它要回答四件事：

1. **去哪里找？** 卡拉曼把价值投资的机会归为三类缝隙（第 0 章）。
2. **要用什么姿态？** 逆向。但这一章要讲透的不是"逆向很酷"，而是那句让人心里发凉的话——**逆向投资者一开始几乎总是错的，而且可能错得比大众更久**（第 1 章）。
3. **有没有免费的线索？** 有。内部人士买入和管理层的薪酬设计，是公开信息里信息量最大的两块（第 2 章）。
4. **便宜怎么变成真的赚到？** 靠催化剂。这是本周的核心（第 3 章），也是六种机会共同的前提（第 4 章）。

> 📌 **划重点：** 前九周你学的是"怎么判断一笔投资好不好"。这一周你学的是
> "**怎么让好投资出现在你面前**"。这两件事完全不同——前者是手艺，后者是地图和耐心。

## 学完这一周，你会得到什么

- 你能说出价值投资的三类机会来源，并且能对着一只具体的股票判断"它属于哪一类，或者哪一类都不是"。
- 你拿到一个**拿到便宜货之后必须先做的动作**：不是买入，是先搞明白"它为什么这么便宜"，并且能区分"公司变差了"和"有人被迫卖"。
- 你能接受并解释那句反直觉的话：**逆向投资者一开始几乎总是错的，而且可能错得比大众更久**——所以你不会在持有的第 18 个月，因为"别人都在赚"而砍在最低点。
- 你会算两笔以前不会算的账：**等待的成本**（同样的折扣，3 年拿到和 10 年拿到，年化差多少）和**风险套利的价差**（错了要几次成功才补得回来）。
- 你认识六种机会的名字和机制，尤其是中国读者完全没见过的"认股权配售"（它的中国版就是配股），以及为什么"分拆"会稳定地创造错误定价。
- 最后一条，也是最重要的一条：**你会知道该把时间花在哪里。** 三年时间里，与其把五千家公司的财报每本都翻一遍，不如盯住那几类"会反复出现便宜货"的地方——**这就是这一周对你钱包的意义：它不提高你的估值水平，它提高你的命中率。**

## 本周术语表（本周新出现的词）

| 词 | 一句话解释 |
|---|---|
| 投资缝隙 | 市场上长期存在"价格明显低于价值"的一小块地方。像一条街上总有几个摊位，东西比别处便宜——因为大多数人懒得走过去 |
| 拆卖价值 | 把一家公司拆成几块分别卖掉，加起来能得到的钱。整台旧车没人要，拆成零件反而好卖 |
| 市场无效 | 信息没有完全传开，或者买卖双方短期失衡，导致价格偏离价值 |
| 机构限制 | 机构投资者自己（或法规）给自己定的规矩，比如"不买 5 元以下的股票""不持有正在被收购的股票" |
| 拆股 / 并股 | 拆股是 1 股切成 5 股，股价变成五分之一；并股是反过来。两者都不改变公司市值 |
| 资产转换 | 你手里的旧证券被换成新证券（现金、新债、新股）的过程 |
| 逆向投资 | 站在人群的对立面买卖。注意：它是"独立算过价值之后碰巧与人群相反"，不是"反着买" |
| 催化剂 | 某个能让"价格向价值靠拢"的事件，比如分拆、清算、被收购、大额回购 |
| 内部人士 | 公司的董事、监事、高级管理人员，以及持股达到一定比例的大股东 |
| 股票期权 | 公司给管理层的一张"未来按今天约定的价格买公司股票"的凭证。股价涨它才值钱 |
| 股权激励 | A 股对"给管理层发股票或期权"的统称，包括限制性股票、员工持股计划 |
| 内幕信息 | 还没公开、但一旦公开就会影响股价的重大信息。用它来买卖是违法的 |
| 清算 | 公司不再经营，把资产卖掉、还完债，剩下的钱分给股东 |
| 复杂证券 | 现金流不按固定节奏发，而是"达到某个条件才发"的证券 |
| 认股权配售 | 公司不给外人发股，而是给老股东一个"按低价、按持股比例认购新股"的权利 |
| 配股 | 认股权配售的中国版：按持股比例、低于市价认购新股，不参与就被稀释 |
| 稀释 | 因为新股发出来，你原来那一股代表的比例变小了 |
| 套利 | 同一件东西在两个地方价格不同，低买高卖赚差价 |
| 风险套利 | 买"正在被收购"的证券，赚收购价与现价之间的差价。赌的是这笔交易能完成 |
| 要约收购 | 收购方公开向全体股东、按一个固定价格买股票 |
| 吸收合并 | 两家公司合并成一家，被合并方的股东按比例换成合并方的股票或现金 |
| 分拆 | 母公司把子公司的股份直接分配给自己的股东，而不是卖给外人 |
| 部分分拆 | 只把子公司的一部分股份分出去，或者把子公司的一部分股份拿去 IPO |
| 封闭式基金 | 份额固定、在交易所像股票一样买卖的基金。它的交易价格可以高于或低于它持有的资产净值 |
| 净值 | 一只基金持有的一篮子资产，平均到每一份上值多少钱 |
| 破产重整 | 公司还不起债，走法律程序，把债务和股权重新安排一遍，目标是让它活下去 |
| 退市整理期 | A 股公司被决定终止上市后、正式摘牌前的一段还可以交易的时期。风险极高 |

## 🔍 动手作业

这一周的作业，是**去公开渠道找一份真实的公告，亲手把它拆开**。
不用开户、不用花钱，只要会查资料、会做四则运算。

### 去哪里查

1. **巨潮资讯网** `www.cninfo.com.cn`（中国证监会指定的信息披露网站）
   → 首页的"公告"搜索框 → 输入下面任意一个关键词：
   - `要约收购报告书`（对应风险套利，第二类机会）
   - `分拆上市`（对应分拆，第三类机会）
   - `重大资产出售`（对应清算与资产转换，第一类和第三类机会）
   - `配股说明书`（对应认股权配售）
2. **港交所披露易** `www.hkexnews.hk`（如果你更关心港股）
   → "披露易" → "标题搜寻" → 输入 `私有化` 或 `分拆`。
3. 找到一份后，把 PDF 下载下来。**只读这一份**，不要贪多。

### 查什么

以一份**要约收购报告书**（或私有化公告）为例，重点读三节：

- **"本次要约收购的方案"**：要约价格是多少？要收购多少比例？
- **"要约收购的生效条件"**：要满足哪些条件，这笔交易才算数？
- **"风险提示"**：公告自己列出了哪些可能导致交易失败的情况？

如果你选的是**分拆上市**公告，重点读：

- 分拆的方式：是母公司股东**按比例直接获得**子公司的股份，还是子公司**单独向社会公开发行**新股？
- 分拆完成后，母公司还持有子公司多少股份？
- 子公司最近一年的收入和利润，在母公司整体里占多大比重？

### 回答这 5 个问题

1. 这件事属于本周六种机会里的哪一类？为什么？（提示：看它的价值是靠什么兜底的）
2. 公告里写明的"退出价格"是多少？公告发布前一个交易日的收盘价是多少？两者相差几个百分点？
3. 时间表上，这件事预计什么时候完成？如果它比计划拖后一年，你的年化回报会掉到多少？（用第 3 章的算法试乘一下）
4. 公告的"风险提示"里，至少找出两条可能导致交易失败或方案变更的情况。写下来。
5. 如果交易失败，股价最可能回到哪个位置？按现在这个价格买入，你的亏损会是多少？

### 判断标准（对答案用）

- **第 1 题**：只要你能说出"它的价值是由资产本身兜底（第一类）、由已知的退出价格兜底（第二类），还是由资产的重新定价兜底（第三类）"，就算过关。分不清也没关系——真正要养成的是**每看到一份公告，先问一句"这里有没有人必须卖"**的习惯。
- **第 2 题**：最容易错的一步是分母。`（退出价 - 现价）÷ 现价` 才是你的潜在收益率；`（退出价 - 现价）÷ 退出价` 算出来是一个更小的数，那不是你的收益。这和 Week 3 算"折价率"时踩过的坑是同一个。
- **第 3 题**：参考答案的形态是"4 个月赚 6%，年化大约 19%；如果拖成 16 个月，年化就掉到 4.5% 左右"。**时间是把年化收益率砍一半的那把刀**，具体数字不重要，重要的是你亲手算过一遍。
- **第 4 题**：常见的答案包括"需要监管机构核准""需要股东大会通过""需要取得债权人同意""交易双方可能就交易条款重新协商""可能存在同业竞争或反垄断障碍"。**能把它们抄下来，你就已经比大多数人读得细了。**
- **第 5 题**：参考答案是"回到消息公布前的价格附近"。这一题的意义在于让你意识到：**风险套利的下行不是 5%，而是 30% 以上。** 所以第 4 章的算一算里，"四次错一次"就足以让整轮变成亏损。
- **加分项**：如果你找到的分拆公告是"子公司单独 IPO"而不是"母公司股东按比例获得股份"，请在答案里注明——这两者对老股东的意义完全不同（第 4 章会讲）。
