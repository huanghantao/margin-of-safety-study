# 本周导读

前六周，我们看的都是"别人是怎么亏钱的"：投机者、华尔街、机构、垃圾债。
从这一周开始，卡拉曼翻到了书的第二部分——**那该怎么办**。

这一周也是整门课的落点。第 3 章要讲的那个词，就是这本书的书名：**安全边际**。
如果十二周里你只能记住一件事，那就是它。

本周对应原书**第五章（明确你的投资目标）**和**第六章（安全边际的重要性）**，
原书 p94 – p118。

## 🎯 学完你会得到什么

- 你能用一句话说清"安全边际"是什么，并且**在纸上算出一家公司在你这个买价上的安全边际是多少**；
- 你会明白**便宜不是感觉，是一个减法**：保守估算的价值，减去你付出的价格；
- 你知道同一家公司，价格越高安全边际越薄，高到某个价位**安全边际会变成零甚至变成负数**；
- 你能分清你的预期收益里，哪一部分来自企业赚钱（可靠），哪一部分来自别人愿意出更高的价（不可靠）；
- 下次市场大跌时，你知道该做的第一件事是**重新算一遍价值**，而不是跟着一起恐慌；
- 面对任何自称"价值投资"的人或产品，你能用一张五行的清单，在十分钟内看出他是不是在演戏。

## 🧭 怎么读这一周（建议 6 小时以上）

1. 先按顺序读第 0、1、2 章（约 2 小时）。这三章都在为第 3 章铺路。
2. **第 3 章至少读两遍**（约 2 小时）。第一遍读故事和定义，第二遍拿纸笔把"算一算"完整算一遍。
3. 第 4、5 章（约 1.5 小时）回答两个问题：跌的时候怎么办？怎么不被骗？
4. 最后做本周的动手作业（约 1 小时）：去巨潮资讯网查一家公司，给**你自己**算一次安全边际。

> 📌 **划重点：** 本周不用背任何公式。只需要记住一个动作：**先估一个保守的价值，再问自己"我付的价格比它低多少"。**

## 🔑 本周术语表

只列本周新出现的词。第一次看不懂不要紧，正文里每个词都会先用生活里的例子讲一遍。

| 术语 | 一句话解释 |
|---|---|
| 安全边际 | 买入价与**保守估算**的价值之间的差距。它是你为自己估错、遇到坏运气留出的容错空间 |
| 无风险利率 | 把钱放在几乎不可能亏本的地方（国债、大行存款）能拿到的利息率。它是所有投资的起跑线 |
| 复利（复合回报） | 赚到的钱不取出来，继续留在里面一起赚，一年一年往后乘 |
| 每股净现金 | 每股对应的现金，减掉公司所有负债之后还剩多少。它常被用来找"跌无可跌"的股票 |
| 每股营运资金净额 | 每股对应的流动资产减流动负债。可以粗略理解为"公司短期能变现的家底" |
| 雷管股票 | 卡拉曼用的词：价格里塞满了高预期，一旦预期落空就暴跌的股票 |
| 有效市场假设 | 一种学术观点：价格已经反映了一切信息，所以研究没有用。它分弱式、半强式、强式三种 |
| 价值套利 | 利用"价格"和"价值"之间的差距赚钱。原书用黄金在两个市场的差价做类比 |
| 封闭式基金 | 一种基金：份额固定，你想卖只能在市场上卖给别人，不能按净值赎回，所以常常打折交易 |
| 有形资产 / 无形资产 | 有形资产看得见摸得着（设备、库存、房产）；无形资产是配方、品牌、口碑这类东西 |
| 催化剂 | 某个能让"价格向价值靠拢"的事件，比如分拆、回购、被收购、清算 |
| 价值骗子 | 卡拉曼的原话是"投资变色龙"：为了吸引资金频繁调整策略，嘴上说价值投资，手上追涨杀跌 |

## 🔍 动手作业

**任务：给你自己算一次安全边际。**

这一周最重要的作业不是读书，是动手。请从本周的案例池里挑**一家**公司来做：
贵州茅台（600519.SH）、长江电力（600900.SH）、福耀玻璃（600660.SH / 3606.HK）、
中国石油（601857.SH / 0857.HK）、招商银行（600036.SH）、中国神华（601088.SH / 1088.HK）、
腾讯控股（0700.HK）。

**去哪里查：**

- A 股公司：**巨潮资讯网** `cninfo.com.cn` —— 首页搜索框输入公司名称或代码，进入公司页面，
  找「定期报告」里的**最新年度报告**（PDF）。
- 港股公司：**港交所披露易** `hkexnews.hk` —— 搜公司名称，找「财务报表 / 年报」。
- 股价：任意行情软件的**市净率（P/B）**一栏，或自己用「股价 ÷ 每股净资产」算。记下查询日期。

**查什么、回答什么：**

1. 在年报里找到「**归属于母公司股东的每股净资产**」（通常在"主要会计数据和财务指标"那一节，
   或者在财务报表附注里）。这是会计账本上每股对应的净资产。**写下你查到的那一页的页码。**
2. 今天这家公司的股价是多少？算出它的市净率：`股价 ÷ 每股净资产`。
   如果结果小于 1，说明市场给它的定价低于账本上记的净资产，这叫**破净**。
3. 翻到年报的「**资产构成**」或「资产负债表」：它的家底里，**有形资产**（厂房、设备、存货、
   房产）和**无形资产**（商誉、商标、专利）各占多少？有没有大额的"商誉"这一项？
4. 写下一句你自己的话：**"如果这门生意明天开始不再增长，我认为它至少值每股 ___ 元。"**
   给出你估这个数的理由（是账本上的净资产？是每年稳定分红？还是靠品牌？）。
5. 用第 4 题的答案做一次减法：`安全边际 = 你估的保守价值 - 今天的股价`。
   把它换算成百分比：`安全边际 ÷ 你估的保守价值`。

**参考答案与判断标准**（没有唯一正确答案，但有几条硬标准）：

- 第 5 题的百分比**低于 20%，通常不算有安全边际**；低于 0 就是完全没有，甚至是"危险边际"。
- 如果你估的"保守价值"主要靠**无形资产**（品牌、配方、口碑）撑着，那么你要的折扣应该**更大**，
  而不是更小——第 3 章会讲清楚为什么。
- 如果你的"保守价值"来自**账本上的有形净资产**，并且公司没有大额商誉、负债不重，
  那么这个下沿相对硬一些。
- 如果你算到一半发现自己根本说不清这家公司靠什么赚钱，**这也是一份合格的作业**：
  你刚刚避开了一个"看不懂的投球"（第 2 章）。
- 请把这次作业的五个答案和计算过程写在一张纸上，夹进你的笔记本。Week 9 我们会再回来，
  用更完整的方法重估一次，到时候你可以对照：你的估计变了多少，为什么变。

> ⚠️ **易踩坑：** 不要在作业里编数字。查不到就写"没查到"，估不出来就写"我估不出来"。
> 一份诚实的"我不知道"，比一个编出来的精确小数有价值得多。
