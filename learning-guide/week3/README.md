# Week 3 导读：先分清投资和投机

Week 1 你知道了股票是什么、公司为什么值钱；Week 2 你学会了给公司估值，也第一次见到了**安全边际**——你保守估算的价值，减去你实际付出的价格。

但这两周的内容都建立在一个前提上：**你真的在乎那家公司值多少钱。** 如果你根本不在乎，你只在乎明天有没有人愿意出更高的价，那么"安全边际"对你毫无意义。

而现实中，第二种人非常多。所以原书在进入正文的第一章，没有先教你算价值，而是先教你**分辨人**：

> "正是由于如此，理解投资和投机之间的区别是取得投资成功的第一步。"（p13）

这一周我们跟着原书第一章走完 p13 到 p29。你会拿到一把尺子，它不能告诉你买什么，但它能告诉你：**你正在做的事情，到底叫什么名字。**

## 🎯 学完你会得到什么

1. **一把可以随身携带的尺子**：面对任何一个买入冲动，你能问出两个问题——我的钱准备从哪里来？我做决定的依据是价值还是价格？
2. **一个不会看错的判断标准**：分辨投资品和投机品只看一条——如果我永远卖不掉它，它还能不能给我带来钱。
3. **正确使用市场报价的能力**：知道报价是来服务你的，不是来指导你的；也知道了 A 股跌停时市场先生会关门不买。
4. **一组算得出来的数字**：亏 10% 到 90% 分别要涨多少才回本；一周交易一次一年要花掉多少本金。
5. **对"公式"的免疫力**：知道为什么"买低市盈率股"可能让你买到更贵的股票，也知道了 A 股那些流行策略为什么会反噬。
6. **对你的钱包意味着什么**：从今天起，你在按下买入键之前会先给自己做一次体检——**如果我说不出这笔钱由谁创造，那我就不是在投资，我是在等一个更傻的人。**

## 🔍 动手作业

本周作业分两部分，都不需要花钱、不需要开户，只需要一台能上网的电脑或手机。**建议先做完作业，再回来看参考答案。**

### 任务一：去官方渠道读一份年报（约 30 分钟）

**去哪里查：**

- A 股：**巨潮资讯网**（`cninfo.com.cn`）——中国证监会指定的上市公司信息披露网站，所有公告的原文都在这里。
- 港股：**港交所披露易**（`hkexnews.hk`）。
- 股价：任意行情软件或交易所官网都可以。

**查什么：** 从下面的名单里挑一家你听说过的公司，找到它**最近一份年度报告**（通常是一份几百页的 PDF，不用全读）：

长江电力（600900）、贵州茅台（600519）、福耀玻璃（600660）、中国神华（601088）、招商银行（600036）。

**回答这 5 个问题：**

1. 这家公司靠什么赚钱？（提示：看年报里"公司业务概要"或"经营情况讨论与分析"开头几页）
2. 去年每 10 股派发现金多少元（含税）？（提示：搜"利润分配"或"权益分派"）把它换算成**每股**多少元。
3. 用你查到的某个交易日的收盘价，算它的**股息率**（每股分红除以股价）。
4. 它的"经营活动产生的现金流量净额"是正数还是负数？大约多少亿元？（提示：在"现金流量表"里）
5. 它的分红，是来自公司自己赚出来的现金，还是来自别的地方？你愿意把它当"投资品"还是"投机品"来对待？

### 任务二：观察一次涨停（约 20 分钟）

**查什么：** 在行情软件里翻一翻最近的涨幅榜或涨停板，随便找一只过去 3 个月里出现过**涨停**的股票。

**回答这 3 个问题：**

1. 涨停那一天，它的成交量比前 5 个交易日的平均成交量大还是小？
2. 那一天公司有没有发公告？去巨潮资讯网按日期查一下，公告说的是什么？
3. 如果你在那天的涨停价买入，你打算赚谁的钱？用第 1 章的尺子给自己分类。

### 参考答案与判断标准

1. **分红数字**：不要求记住具体金额，要求你说得出"这个数字来自年报的哪一节"。能自己找到，就算过关。
2. **股息率**：算法是"每股分红除以股价"。这个数字因公司和股价而异，一般落在百分之几的范围内，**只要你亲手算出来就对了**。注意：只要分红没变，股价越跌，股息率就越高——这正是第 4 章讲的陷阱的伪装。
3. **现金流**：如果一家公司长期"经营活动产生的现金流量净额"是正数，而且和净利润大体匹配，说明它赚的是**真钱**；如果净利润很好看、现金流常年为负，那就要打问号。
4. **最关键的一问是第 5 题**。判断标准是：如果你说不出这家公司靠什么赚钱，或者你买它的唯一理由是"它在涨"，那么无论它多有名、多大，你都是在**投机**——因为你的收益必须由下一个买家掏出来。
5. **任务二的隐藏答案**：涨停那天公司的公告，很多是"股票交易异常波动公告"，内容常常是"公司目前经营正常，不存在应披露而未披露的重大事项"。**这句话正好说明了第 2 章的道理**：价格的剧烈波动可以发生在企业实体状况毫无变化的时候——它反映的是供求和情绪，不是价值。

## 📖 本周术语表

只列本周新出现的词（Week 1、Week 2 已经解释过的词不再重复）。

| 术语 | 一句话解释 | 生活里的类比 |
|---|---|---|
| 投机 | 靠预测价格下一步涨跌来买卖，赌的是别人会出更高的价 | 抢椅子游戏：音乐停之前把椅子传出去 |
| 投资 | 基于对企业价值的分析，以低于价值的价格买入，赚的是价值本身 | 盘下一家小店的股份，靠它每年赚的钱回本 |
| 投资品 / 投机品 | 投资品会为持有人带来现金流，投机品不会 | 会下蛋的母鸡，和一枚只会涨价的纪念币 |
| 博傻（更大傻瓜理论） | 明知价格已经很高，但相信有更傻的人会接手 | 击鼓传花，只要鼓声不停就没事 |
| 技术分析 | 用过去的价格走势来预测未来的价格，而不是企业价值 | 只看体重曲线猜一个人会得什么病 |
| 净值（NAV） | 一只基金手上的资产按市价算值多少钱，除以份额 | 把一篮子东西估个价，再除以份数 |
| 封闭式基金 | 份额固定的基金，只能像股票一样卖给别的投资者，价格可以高于或低于净值 | 一张不能退、只能转卖的会员卡 |
| 市场先生（Mr. Market） | 格雷厄姆的比喻：市场像一个情绪极不稳定的合伙人，每天给你报一个价，你可以接受也可以无视 | 每天准时敲门、报价忽高忽低的合伙人 |
| 有效市场（假说） | 认为所有信息都已经反映在价格里，试图战胜市场是徒劳的 | 菜市场里每棵白菜的价格永远是对的 |
| 供求关系 | 想买的人和想卖的人谁更急，价格就往谁那边走 | 下雨天打车，车少人多，价格就上去了 |
| 垃圾债券 | 信用评级低、违约风险高的公司发的债券，靠高利息才卖得出去 | 信用不好的人借钱，得付更高的利息 |
| 杠杆收购（LBO） | 借钱把一家上市公司整个买下来，用公司自己的现金流还债 | 首付两成买房，用租金还月供 |
| 收益猪（yield pigs） | 华尔街的绰号：只看收益率高低、不在乎本金安全的投资者 | 只盯着赠品，没看商品本身多少钱 |
| 名义回报 / 通胀 | 名义回报是账面上看到的百分比；通胀是物价普遍上涨、钱变毛了 | 利息拿了 12%，物价涨了 9%，实际只多 3% |
| 买入期权（看涨期权） | 在约定的期限内、以约定的价格买入某个证券的**权利** | 先付定金锁定一个买房价格 |
| 期权收益基金 | 买债券的同时卖出买入期权，把期权费当"收益"发给你；上涨的好处没了，下跌的风险还在 | 省下保险费，但房子着火了自己扛 |
| 按揭抵押证券（Ginnie Mae） | 把许多房主的房贷打包成证券卖给投资者，每月分配里既有真利息，也有本金的偿还 | 收到的钱里一部分是利息，一部分是自己的本金 |
