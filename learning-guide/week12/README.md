# 本周导读

十周以前，我们一直在做同一件事：**学会看懂一家公司，并算清楚它值多少钱。**
Week 10 和 Week 11 又把"去哪里找机会"讲完了——清算、分拆、配股权、风险套利、
困境证券、破产重整。

可是还差最后一步：**这些东西要怎么装进一个真实的人的钱包里？**

这一周是全课程的最后一周。它不再教你新的分析方法，而是回答三个非常具体的问题：

1. **钱怎么摆？** 现金留多少、买几只、要不要对冲、什么时候该卖（第 0–2 章）；
2. **我不想自己选股怎么办？** 基金、ETF、私募、投顾，以及怎么评估一个替你管钱的人（第 3 章）；
3. **学完之后我到底该做什么？** 一张能打印出来、买前逐项打勾的清单（第 4 章）。

本周对应原书**第十三章（投资组合管理和交易）**、**第十四章（个人投资者的投资替代品）**，
以及**附录二、附录三和编后记**，原书 p223 – p241、p253 – p281。

> 📌 **划重点：** 这一周没有新的公式。它的价值在于**把前十一周学过的东西变成动作**。
> 如果你只读一周，读这一周；如果你只打印一页，打印第 4 章的那张清单。

## 🎯 学完你会得到什么

- 你能说出**流动性的三层含义**，并给自己定下"哪些钱永远不进股市"；
- 你知道**买 5–10 只**和买 30 只的差别在哪，以及为什么"买 10 只银行股"根本不叫多样化；
- 你会用一张手算表算出**分批买入之后你的每股平均成本**，并知道为什么卡拉曼要求你"为以低于平均价格买进留出空间"；
- 你能背出卖出的四个问题，并且能一眼认出"止损线卖出"为什么是原书说的**疯狂做法**；
- 你知道自己付的**每一笔基金费用**是什么，并能在纸上算出每年多付 1.5 个百分点、
  30 年后会少拿多少钱；
- 你手里会有一张**可以打印出来、买前逐项打勾的检查清单**——五组、23 条、每条都能回答"是/否"；
- 最后回答：**学完这十二周，我明天该做的第一件事是什么。**

## 🧭 怎么读这一周（建议 6 小时以上）

1. 先读第 0、1 章（约 1.5 小时）。它们回答"钱怎么摆"，是第 2 章的地基。
2. **第 2 章至少读两遍**（约 2 小时）。这是全课程最后一次讲"动作"：
   买要分批，卖要有理由。把"算一算"完整算一遍，你会真的记住那个 15.38 元。
3. 第 3 章（约 1.5 小时）。如果你以后可能买基金，这一章的"算一算"是全周最省钱的一道题。
4. **第 4 章（约 1.5 小时）慢慢读。** 把那张检查清单抄一遍，或者直接打印出来，
   贴在你下单时会看到的地方。
5. 做完动手作业（约 1 小时）：拿一家你真感兴趣的公司，走一遍完整流程。

> ⚠️ **易踩坑：** 不要因为这是最后一周，就急着"学完好去赚钱"。
> 这一周真正的产出不是一份买入名单，而是**一份能让你少犯错的操作手册**。
> 原书的编后记专门提醒过这件事——十二周学完，你最大的收获应该是"知道投资不简单"，
> 而不是"觉得投资很简单"。

## 🔑 本周术语表

只列本周新出现的词。第一次看不懂不要紧，正文里每个词都会先用生活里的例子讲一遍。

| 术语 | 一句话解释 |
|---|---|
| 流动性 | 你想把一样东西换成现金时，能不能换、要多久、要打多少折 |
| 流动性周期 | 投资的过程：现金 → 流动性差的投资 → 赚到钱 → 重新变回现金，然后重来一遍 |
| 排堵效应 | 定期把一部分持仓变现，逼自己重新审视每一笔投资，不让"没有价值的证券越积越多" |
| 多样化投资 | 把钱分散到几只不同的证券上，用来降低"某一家公司自己出事"带来的损失 |
| 市场风险 | 整个股市一起跌的那部分风险。它无法靠多样化消除 |
| 个股特有风险 | 只有某一家公司会遇到的风险（工厂出事、产品失败）。它可以靠多样化大幅降低 |
| 对冲 | 同时持有一笔能"反向变动"的头寸，用来抵消市场或某个价格因素的波动 |
| 摊薄成本 | 在更低的价格继续买入同一只证券，从而拉低你的每股平均成本 |
| 止损订单 | 预先设定"跌到某个价格就自动卖出"的委托。原书称这种做法是疯狂的 |
| 共同基金 | 很多人把钱凑在一起交给一家公司统一管理。开放式基金可随时按净值申赎，封闭式基金只能在市场里卖给别人 |
| 基金净值 | 基金持有的全部资产按市价算出来、再除以份额，得到每一份值多少钱 |
| 管理费 / 托管费 | 基金按年从资产里扣走的两笔固定费用，和业绩好坏无关 |
| 申购费 / 赎回费 | 你买入、卖出基金时一次性交的费用；C 类份额则用"销售服务费"按年收 |
| ETF | 交易型开放式指数基金：像股票一样在交易所买卖，费率通常比主动基金低 |
| 全权股票经纪人 | 你把账户的操作权交给他，他替你决定买什么卖什么。原书提醒这有巨大的利益冲突 |
| 资金管理人 | 替别人管钱的专业人士。评估他要看人品、公平、规模、哲学和历史业绩 |
| 业绩报酬 | 私募类产品常见的收费方式：赚了钱，管理人从收益里再分走一部分 |

## 🔍 动手作业

**任务：把结业清单真的走一遍。**

这一周的作业不需要新知识，只需要你**把学到的东西用一次**。
请挑**一家**你真正感兴趣的公司（从案例池里选最省事：
贵州茅台 600519.SH、长江电力 600900.SH、福耀玻璃 600660.SH / 3606.HK、
中国石油 601857.SH / 0857.HK、招商银行 600036.SH、中国神华 601088.SH / 1088.HK、
腾讯控股 0700.HK），然后做三件事。

### 第一部分：走一遍第 4 章的检查清单

把第 4 章的五组清单抄到一张纸上（或者打印出来），**逐条打勾或打叉**。
不允许出现"大概吧""应该算吧"这类答案——每一条都必须落到"是"或"否"。

**去哪里查：**

- A 股公司：**巨潮资讯网** `cninfo.com.cn` —— 搜公司名称或代码，找「定期报告」里的**最新年度报告**。
- 港股公司：**港交所披露易** `hkexnews.hk` —— 搜公司名称，找「财务报表 / 年报」。
- 公司的生意介绍：年报开头的「**公司业务概要**」或「**经营情况讨论与分析**」那一节。

**回答哪几个问题（每个都要写下你查到的页码或栏目名）：**

1. 这家公司靠什么赚钱？请用**一句话**说清楚，句子不许出现"等""之类""相关"这类含糊的词。
2. 它去年赚到的**经营现金流**是多少？和它的**净利润**相比，是更多还是更少？
3. 它的账本上有没有大额的**商誉**？占净资产的比重大概多少？
4. 你保守估算它值每股 ___ 元。这个数字是怎么来的（账本净资产？每年分红？还是别的）？
5. 今天的股价是多少？`安全边际 = 你估的保守价值 - 股价`，结果是多少、占保守价值的百分之几？

### 第二部分：算一次分批买入

假设你准备为这家公司投入 6 万元，并且打算**分三批**买入。

6. 写下你的三批计划：什么价位买多少、每批占总金额的多少。
   提示：第 2 章讲过的常见做法是每批三分之一，并且**第一批的价格必须已经有安全边际**，
   跌下来之后的第二、三批是"更便宜"，不是"越跌越买来摊平一个错误"。
7. 用第 2 章「算一算」的方法，把这三次买入的**平均成本**算出来
   （总花的钱 除以 总股数；A 股下单要按整手来——主板、创业板、北交所 100 股起，
   **科创板 200 股起**）。

### 第三部分：看一眼你可能买的基金的费率

8. 如果你打算用基金代替自己选股：找一只你看得懂的基金（宽基 ETF 最省事），
   在它的**基金合同**或**招募说明书**里找到这几个数字：管理费年费率、托管费年费率、
   申购费、赎回费（或销售服务费）。
9. 把这些费用加起来，用第 3 章的表格估一下：如果你投 10 万元、持有 30 年，
   每年多付 1 个百分点，大约会少拿多少钱？

**参考答案与判断标准**（没有唯一正确答案，但有硬标准）：

- 第 1 题如果你写不出那句不含糊的话，**这是合格的结果**：你刚刚避开了一个"看不懂的投球"。
  请老实写"我讲不清它怎么赚钱"，然后把这家公司放下。
- 第 2 题：经营现金流长期**明显低于**净利润的公司，要格外小心（Week 2 和 Week 6 都讲过这件事）。
- 第 4 题：如果你的"保守价值"主要靠品牌、口碑这类**无形资产**撑着，
  你要求的折扣应该更大，而不是更小（Week 7 第 3 章讲过为什么）。
- 第 5 题：安全边际率**低于 20% 通常不算有安全边际**；低于 0 就是"危险边际"。
- 第 8、9 题：费率没有绝对的好坏，只有"你知不知道自己在付什么"。
  说不清费用结构的基金，先放下。
- 请把这份作业和 Week 7、Week 9 的作业放在一起对照：**同一家公司，你的估值变了多少？为什么变？**
  这个问题比任何一次买卖都更值钱。
