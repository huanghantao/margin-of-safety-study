# 本周导读：华尔街不是你的敌人，但它绝对不是你的朋友

> 上周我们认识了三位主角：**投资者**、**投机者**，和那位情绪极不稳定的**市场先生**。
> 我们学到最重要的一句话是：价格由情绪决定，价值由生意决定，两者可以差很远。
>
> 但这里还有一个问题没回答：**每天在你耳边说话的那些人，靠什么吃饭？**
> 券商、基金公司、销售平台、财经主播、研报分析师……他们不是市场先生，
> 他们是有名有姓、有考核指标、要发工资的机构。
> 这一周，我们把他们的收入结构摊开在桌面上，一笔一笔看清楚。
>
> 这一周你不需要买任何东西，也不需要开任何账户。
> 你只需要读完，然后在下一次有人向你推荐什么的时候，能多问一句："**这笔钱是谁付的？**"

## 学完这一周，你会得到什么

1. **一张"收费方名单"**：你能说出买一次股票、买一只基金，钱分别流向了哪几个口袋，各自大概多少。
2. **一个判断信息的方法**：拿到任何一条"推荐"，你会先问"说这话的人靠什么吃饭"，再决定给它打几折。
3. **一笔算得出来的账**：你会亲手算出，同样 10 万元、同样 8% 的毛收益，每年 0.2% 和 1.4% 的费用在 30 年后会差出多少。
4. **一套识别新产品的动作**：面对任何"创新产品"，你会问三个固定问题，不用懂它的全部细节也能避开大部分坑。
5. **一个反直觉的结论**：费用是你账户里**唯一确定会发生**的支出——不管涨跌，它都会发生。
6. **这对你的钱包意味着什么**：从这一周起，你在下单之前会先看一眼费率，并且**不再因为一条"买入"评级就动手**。这一条，长期看比选对一只股票更值钱。

## 本周术语表（只列本周新出现的词）

> 每个词第一次在正文出现时，都会先用生活里的东西打比方，再给定义，最后落到 A 股/港股。
> 这里是速查表，读完正文再回头看一遍。

| 词 | 一句话解释 |
|---|---|
| **佣金** | 别人帮你撮合成交，你付的手续费。就像房产中介帮你撮合买卖，成交了收你一笔钱 |
| **承销** | 公司要发行新股票或新债券，找券商帮忙卖出去；券商收的费用叫承销费。就像出版社帮你出书，从书款里抽成 |
| **投资银行（投行）** | 券商里专门做"帮公司融资、并购、上市"这块业务的部门。名字里有"银行"，但它不办存贷款 |
| **一级市场** | 证券**第一次**从发行方卖到投资者手里的市场。在这一步，钱从投资者流向公司 |
| **二级市场** | 投资者之间互相买卖**已经发行**的证券的市场。钱在投资者之间转手，公司拿不到 |
| **IPO（首次公开发行）** | 一家公司第一次把自己的股票拿出来公开卖 |
| **卖方 / 买方** | 卖方 = 卖研究报告和交易服务的（券商研究所）；买方 = 拿着钱真正去投资的（基金、保险、也包括你自己） |
| **卖方研报** | 券商研究所写的、免费发给客户看的研究报告。它靠经纪业务和投行业务赚钱，不靠研报本身的准确性赚钱 |
| **做空** | 先借来股票卖掉，等价格跌了再买回来还回去，赚中间的差价。和先买后卖的"做多"正好相反 |
| **熔断** | 市场跌得太快时，交易所强制暂停交易一段时间，让大家冷静一下 |
| **管理费** | 基金公司按你持有金额的固定比例、每年收的钱。赚了收，亏了也收 |
| **托管费** | 银行替你保管基金资产、监督资金流向，每年收的钱 |
| **申购费 / 赎回费** | 买基金时付的钱叫申购费，卖基金时付的钱叫赎回费 |
| **净值** | 一只基金的全部资产减去负债，再除以总份额——也就是"每一份值多少钱" |
| **溢价 / 折价** | 交易价格比净值**高**叫溢价，比净值**低**叫折价 |
| **封闭式基金** | 发行时收一笔钱、份额固定，之后只能在交易所里跟别人买卖，不能按净值赎回 |
| **开放式基金** | 随时可以按净值向基金公司申购或赎回的基金。今天你在 App 上买的大多数基金都是这种 |
| **换手** | 把手里的东西卖掉再买回来。"一年换手 4 次"就是一年里买卖了 4 个来回 |
| **印花税** | 国家对股票卖出方单边征收的一种税。买入不收，卖出才收 |
| **抵押贷款支持证券** | 把一大堆房贷打包成一个资产池，再以这个池子的还款为担保发行证券。买房人还的钱，转手就成了证券持有人的收入 |
| **IOs / POs** | 把一笔房贷的还款剪开：只拿利息的那一半叫 IO，只拿本金的那一半叫 PO |
| **金融创新** | 设计出以前没有的证券或产品。它不一定是为了让客户赚更多，也可能是为了让中介多收一笔费用 |
| **自证预言** | 因为大家都相信某件事会发生，他们的行为反而让这件事真的发生了。这里指：大家相信会涨，于是买入，价格真的涨了 |

## 🔍 动手作业

> 这一周的作业**不用花一分钱，也不用开户**。你只需要打开几个公开页面，把答案抄在纸上。
> 全部做完大约 60 分钟。做完之后，你对"谁在赚你的钱"会从"听说"变成"知道"。

### 任务 A：算出你自己的"费率表"（约 20 分钟）

**去哪里查：** 任意一家券商的官网或 App 的"费率说明 / 帮助中心"页面（搜索"某券商 佣金 费率"即可）。
不需要开户，费率说明通常是公开的。

**回答下面 4 个问题：**

1. 这家券商的 A 股佣金费率是"万分之几"？（很多券商写着"不高于成交金额的千分之三"，但实际默认或可协商的费率往往低得多——把两个数字都记下来。）
2. 有没有"最低 5 元"这样的单笔最低收费？如果有：假设你只买 2000 元的股票，5 元最低收费相当于多少百分比？
3. 融资融券的利率大概是多少（年化）？
4. 这家券商代销基金时，申购费打几折？

**参考答案或判断标准：**

- 第 2 题是本任务的重点。5 除以 2000 等于 0.25%，也就是千分之二点五——**比大额交易的佣金贵近十倍**。这说明"小额频繁买入"的隐形成本极高。如果你的答案算出来超过 0.1%，请把"每次少买一点、多买几次"这个习惯从你的计划里划掉。
- 第 1 题只要你找到了确切数字就算完成。记住一点：**佣金是可以谈的**，不同券商、不同客户差别很大。
- 第 4 题：大多数第三方平台会把申购费打到 1 折左右，而银行渠道常常不打折或只打很小的折扣。同样一只基金，渠道不同，你付出的申购费可能差好几倍。

### 任务 B：拆开一只基金的费用（约 25 分钟）

**去哪里查：** 巨潮资讯网（cninfo.com.cn）或基金公司官网，搜索任意一只公募基金的**《基金合同》**或**《产品资料概要》**。
提示：《产品资料概要》是一份两三页的简版说明书，专门写给普通投资者看，比合同好读得多，优先找它。

**回答下面 5 个问题：**

1. 这只基金的管理费年费率是多少？托管费年费率是多少？
2. 申购费和赎回费怎么收？赎回费是不是"持有时间越短收得越多"？
3. 这份文件里有没有"客户维护费"或"尾随佣金"的字样？比例是多少？
4. 把管理费加托管费，等于每年百分之几？
5. 拿第 4 题的答案乘 10 万，等于每年多少钱？

**参考答案或判断标准：**

- 第 3 题是本任务的重点，也是最少人知道的一条。**"客户维护费"是基金公司从自己的管理费里，分给销售渠道的钱。**它的存在意味着：渠道推荐某只基金，不一定因为那只基金好，也可能因为那只基金分给它的钱多。找不到这一条也没关系，把"我找过"记下来就行。
- 第 4 题：主动管理的股票基金常见在 1.4% 左右（管理费约 1.2% 加托管费约 0.2%）；宽基指数基金常见在 0.2% 左右。这两个数字的差距，就是第 4 章那张图要讲的事。
- 第 5 题：1.4% 乘 10 万等于每年 1400 元。请把这个数字写进你手机的备忘录——它是**每年都会发生**的，不管基金赚不赚钱。

### 任务 C：看一份"投资者关系活动记录表"（约 15 分钟）

**去哪里查：** 巨潮资讯网（cninfo.com.cn）。在首页搜索框输入一家上市公司的股票代码，进入公司页面，找公告分类里的**"投资者关系活动记录表"**。
（港股对应的是港交所披露易 hkexnews.hk，找业绩发布会材料或分析师简报。）

**回答下面 4 个问题：**

1. 最近一次记录里，有多少家机构来调研？都是什么类型的机构（基金公司、券商、私募）？
2. 机构问的问题，偏"今年能增长多少"，还是偏"这个风险你们怎么应对"？
3. 公司的回答里，有没有出现"预计""力争""有望"这类词？出现了几次？
4. 整份记录里，有没有任何一个机构提出了明确的质疑或反对意见？

**参考答案或判断标准：**

- 第 4 题几乎没有例外，答案都是"没有"。原因和第 1 章讲的一模一样：**来调研的机构，绝大多数是手里拿着钱、正在考虑买入的人**。想买的人问不出真正的坏问题——这是结构决定的，不是人品问题。
- 第 3 题如果你数出来的"预计/力争/有望"超过 5 次，说明这份记录里**承诺性的语言多于事实性的语言**。这类记录读的时候要整体打折。
- 这份作业真正的收获是：你从此知道了一个**不花钱、不经过任何中介、来自公司自己**的信息源在哪里。以后别人给你讲某家公司的故事，你可以自己去看原文。

## 写在开始之前

> ⚠️ **易踩坑：** 读完这一周，很容易得出一个结论："券商和基金公司都是骗子。"
> **这个结论是错的，而且对你没有用处。**
>
> 正确的心态就是原书 p30 的意思：投资者无需因此而谴责华尔街，
> 只要时刻牢记这一点，并在任何一项自己可能参与的交易中**保持谨慎怀疑的态度**就可以了。
>
> 医生、律师、理发师也都是先收钱、不管最终结果。这不代表他们想害你，
> 只代表**你不该把他们的意见当成免费的、中立的真理**。
> 你该做的不是骂他们，而是把自己变成一个"知道对方靠什么吃饭"的客户。

准备好了就翻到第 0 章。我们从一个最简单的问题开始：**你按下"买入"的那 10 万元，到底去了几个地方？**
