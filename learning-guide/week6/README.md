# 本周导读

> **本周你将：**
> - 搞懂"债券"和"股票"到底差在哪里，以及为什么"借条"也分三六九等
> - 用五个问题听懂 20 世纪 80 年代美国垃圾债从兴起到崩塌的全过程
> - 学会看"违约率"这个数字背后的分子和分母，知道它为什么可以被算小
> - 掌握一张能自己动手算的桥接表：从净利润一路算到真正的自由现金流
> - 拿到一份十二个问题的识别清单，用来躲开今天 A 股/港股 里的高收益陷阱
> - 最后回答：**别人买垃圾债亏钱，为什么也会烧到你；以及这对我的钱包意味着什么**

上一周（Week 5）我们看清了机构投资者的处境：他们被季度排名、满仓要求、风格分类绑住手脚。这一周我们换一个角度——**当一大群人同时被绑住手脚、又被一个好听的故事吸引时，市场会变成什么样。** 原书的第四章讲的就是这样一个故事：美国的 20 世纪 80 年代，一种叫"垃圾债"的东西被包装成"高收益、低风险"的完美投资，最后给投资者造成了数百亿美元的损失。

这一章的时代感最强：里面的人名（米尔肯）、机构名（德崇证券）、产品名（零息债、PIK 债、EBITDA）你大概率一个都没听过。所以本周的写法是：**先花三五句话交代当年发生了什么，再把机制抽出来，最后落到今天 A 股/港股 里能用的判断方法。** 背景只是入场券，重点永远是"今天怎么用"。

## 🔤 本周术语表

只列本周**新出现**的词。第一次遇到看不懂的词，回到这张表。

| 词 | 一句话解释 | 生活里的类比 |
|---|---|---|
| 债券 | 一张借条：你把钱借给对方，对方按约定付利息、到期还本 | 借给亲戚 10 万元，说好每年给利息、三年后还本 |
| 面值（票面价格） | 印在债券上的那个数，也就是到期对方应该还你的本金 | 欠条上写的"今借到 100 元" |
| 票息（息票） | 债券每年按面值付给你的利息 | 说好"每年给 5%" |
| 信用评级 | 专业机构给借款人打的"信用分"，分数低意味着更可能还不上 | 银行给你的贷款额度，取决于你的收入流水 |
| 投资级 / 投机级 | 评级分成两大档。投资级是"看起来还得起"，投机级是"能不能还上要看运气" | 信用卡提额被拒的那一类 |
| 垃圾债（高收益债） | 投机级债券的俗称。名字难听，但它的另一个名字"高收益债"是从卖方的角度起的 | 愿意付 15% 利息才借得到钱的人 |
| 堕落天使 | 原本是投资级、后来被降级到投机级的债券 | 原本的优等生掉了成绩 |
| 违约 | 没按约定付利息或者还本金 | 借钱的人到期说"我还不上" |
| 违约率 | 在一定时间里违约的债券，占全部债券的比例 | 一个班里 50 个同学借钱，有 3 个没还 |
| EBITDA | 息税折旧摊销前利润。把利息、税、折旧、摊销都加回去之后剩下的那个数 | 一个人说自己"月薪三万"，但没扣房租、没扣税、没扣车贷 |
| 自由现金流 | 公司经营赚到的现金，减去维持生意必须花掉的钱之后，真正能自由支配的部分 | 工资减掉房租饭钱之后，能存下来的钱 |
| 资本开支 | 为了维持或扩大生意，花在设备、厂房上的钱 | 出租车司机换轮胎、修发动机的钱 |
| 折旧与摊销 | 会计上把一笔大额支出分摊到好几年里扣掉，它不产生当期现金流出 | 一次性花 30 万买的车，账上按 10 年慢慢扣 |
| 商誉 | 收购时出价高于对方账面净资产的那部分，记成一项"无形资产" | 买一家旺铺，付的钱比店里的桌椅锅碗值钱多得多 |
| 零息债 | 中途一分钱利息都不付，到期一次性还本付息的债券 | 现在拿 75 元，五年后还你 100 元 |
| PIK 债（实物付息） | 利息不用现金付，而是"再给你打一张欠条" | 借条上再加一行"去年的利息也算成本金" |
| 杠杆收购（LBO） | 借钱把一家上市公司整个买下来，用公司自己的现金流还债 | 首付靠借，月供靠房租 |

## 🔍 动手作业

本周的作业就是去公开渠道，亲手看两份真实的公开文件。**不需要看懂全部，只需要回答下面几个问题。**

### 作业 A（必做）：一家公司的钱，是真的还是账面的

- **去哪里查**：巨潮资讯网（cninfo.com.cn）——这是中国证监会指定的上市公司信息披露网站。打开首页，在搜索框里输入"贵州茅台"或其代码 `600519`，进入公司页面，找到最近一份**年度报告**，下载 PDF。
- **查什么**：在年报里找到三张表——「合并利润表」「合并现金流量表」，以及附注里关于「商誉」的部分（可以用 PDF 的查找功能搜"商誉"两个字）。
- **回答这几个问题**：
  1. 这一年的**净利润**是多少？
  2. **经营活动产生的现金流量净额**是多少？它比净利润大还是小？
  3. **购建固定资产、无形资产和其他长期资产支付的现金**是多少？（这一项就是"资本开支"）
  4. 用「经营现金流净额 - 资本开支」这个粗略口径，算一下它的自由现金流大约是多少？
  5. 这家公司的资产负债表上有没有"商誉"？占净资产的比例大概是多少？
- **判断标准**：如果你的数字显示①经营现金流大于或接近净利润，②资本开支远小于经营现金流，③商誉很小甚至没有——说明这门生意的利润基本是"真钱"，不太需要靠不断投钱来维持。三项里有任何一项相反，就把它记到你的观察名单上，多问几个为什么。**不用精确到小数，量级对就够了。**

### 作业 B（选做）：一张"高收益"的借条长什么样

- **去哪里查**：香港交易所披露易（hkexnews.hk）。在搜索框里输入一家你听说过的、内房行业的公司名字，找到它发行的**美元债**相关公告。
- **回答这几个问题**：
  1. 这张债券的票面利率是多少？是每年付现金，还是允许"实物付息（PIK）"？
  2. 同期美国国债的收益率大概是多少？两者的差距有多大？
  3. 公告里有没有提到"利息递延""选择性付息""抵押物"这些字眼？
  4. 如果你是出借方，看到上面这些条款，你最担心什么？
- **判断标准**：票面利率越高（比如到了两位数），说明市场认为它越可能还不上；如果条款里出现 PIK 或者"利息可以递延"，说明发行人自己也做好了"现在不掏现金"的准备。**利率高不是好事，它是风险的价格。**
