## 为什么要有这一周

先看两个生活场景。

**场景一：制度变了，价格还没跟上。**

你住的小区里有一家开了二十年的"员工合伙小超市"——它没有股东，
出钱的人和干活的人是同一批人。某一天它宣布改成股份有限公司，
拿出三分之一的股份卖给街坊，每股 10 元。
超市本身的家底（货架、仓库、二十年的老客户）值 100 万元，
街坊们买股又投进来 100 万元，公司账上一下子变成 200 万元。
**你花 10 元买的那一股，背后立刻对应着 20 元的家底。**

这不是运气，是**转制这个动作本身**带来的算术结果。
原书第十一章讲的就是这件事，只不过主角换成了美国的储蓄机构。

**场景二：一家公司快不行了，它的债券能买吗？**

一家公司欠了 100 亿元，现在所有人都不相信它能还上，
于是它的一张"面值 100 元"的债券在市场上只卖 32 元。
问题来了：**这 32 元到底是贵还是便宜？**

用 Week 9 学的"算未来现金流折现"完全没有用——这家公司明年的现金流是正是负
都没人说得清。你唯一能做的事是：
**列出它可能落到哪几种下场，每种下场你能拿回多少钱，各有多大可能，
然后乘一乘、加一加。** 这就是第十二章的核心技术。
这一周的第 3 章会带你完整地手算一遍。

> 📌 **划重点：** 这一周的两章，表面上一个讲"制度"，一个讲"破产"，
> 底层其实是同一件事：**当多数人因为"看不懂""嫌麻烦""觉得脏"而集体不看的时候，
> 价格就会偏离价值。** 你要做的是先把这件事看懂，再看它值多少钱。

## 学完这一周，你会得到什么

- 你能用一句大白话向别人解释**互助制**和**转制**，并说出为什么转制会给新股东
  带来一次**一次性的**便宜。
- 你能说出企业陷入困境的三条主要路径，并且能在一家公司的公告里认出
  "现金撑不住了"的早期信号。
- 你能区分**清算、重整、被收购、彻底归零**这几种结局，并说清每一种下
  不同等级的证券分别能拿回什么。
- **最重要的一条**：你能拿一张纸，列出几种结局、各自的回收金额和大致概率，
  乘一乘、加一加，算出一个**加权期望回收值**，然后拿它和市价比较，
  判断这笔投资有没有安全边际。
- 你能说出困境证券最坑人的三个地方：**回报率高度依赖"要等多久"**、
  **市场极度缺乏流动性**、**破产企业的普通股常常贵得离谱**。
- 最后一条，回答"**这对我的钱包意味着什么**"：
  你会知道自己**大概率不应该**去买困境证券，但你能从这一周学到一套
  看资产负债表的新眼光——**先问"万一出事，我还剩什么"，再问"能赚多少"**。

## 本周术语表（本周新出现的词）

| 词 | 一句话解释 |
|---|---|
| 储蓄机构（S&L） | 美国的"存钱放贷"小银行。主业是把居民存款收进来，放成二三十年的住房贷款。像中国早年的城市信用社、农村信用社 |
| 互助制 | 一种"没有股东"的所有制：机构归**存款人**共同所有，赚了钱留在机构里，不发给谁。像员工合伙开的店——出钱的人和用店的人是同一批人 |
| 转制 | 互助制改成股份制：把原本"没有股票"的机构，变成一家有股票、能在交易所买卖的公司，并向存款人、管理层和公众发行股票 |
| 财政困境 | 一家公司的现金连"维持经营 + 按时还债"都满足不了的状态 |
| 违约 | 到了约定的日子，没有按约定付利息或还本金 |
| 证券交换 | 公司拿"新证券"去换债权人手里的"旧证券"，等于**不进法院的重组** |
| 搭便车 | 别人让步、我死守，我占最大便宜。债权人越多、越分散，这个问题越严重 |
| 预先包装的破产 | 进法院之前就把重组方案谈好、让多数债权人签了字，进去只是走程序。几个月就能出来，不用拖几年 |
| 破产保护（重整） | 向法院申请保护，暂停所有追债，然后在法院监督下重谈债务、继续经营。中国对应的是《企业破产法》里的**重整**程序 |
| 自动冻结 | 破产申请一提交，几乎所有针对这家公司的追债、诉讼、强制执行都要停下来 |
| 债权等级 | 分钱时的排队顺序。排在最前面的是有担保债权人，排在最后的是普通股股东 |
| 有担保债务 | 借条背后押了具体资产（房子、设备、飞机）。还不上就把押品卖掉还你 |
| 无担保债务 | 只凭公司信用借的钱，背后没有指定资产 |
| 次级债券 | 无担保债务里**排在后面**的那一档，别人分完才轮到它 |
| 支点证券 | 资产价值只覆盖了它**一部分**的那一档证券：往上走它受益最大，往下走它受伤最重 |
| 回收值 | 公司违约或破产后，某一档证券**实际能拿回来**的钱。通常按"每 100 元面值能拿回几元"来说 |
| 加权期望回收值 | 把每种结局的回收金额乘上各自的概率，再加起来。**它不是保证，是一个用概率表达的平均值** |
| 市场间套利 | 同一家公司，在股市和债市上被标出了互相矛盾的价格；同时买入便宜的一边、卖出贵的一边，把差距锁住 |
| 做空 | 先借来证券卖掉，等价格跌了再买回来还回去，赚中间差价。价格涨了就会亏，而且理论上亏损没有上限 |
| 退市风险警示 | 交易所给投资者的风险提示标记（股票简称前面加 `*ST`）。触发的情形和标准由交易所规则规定，规则会修订，以现行规则和公司公告为准 |

## 🔍 动手作业

这一周的作业，是**亲手去公开渠道翻一家"出了问题"的公司的公告**，
然后自己回答"它还撑得住吗"。

不用开户，不用花钱，只要会上网查资料、会用计算器。

### 去哪里查

1. **巨潮资讯网** `www.cninfo.com.cn`（中国证监会指定的信息披露网站）。
   在搜索框里搜关键词 **"债务逾期"**、**"被申请重整"**、**"法院受理重整"**、
   **"退市风险警示"**，会跳出一批公告。**任选一家**你看着眼熟的 A 股公司。
2. 找到这家公司的**最近一期年度报告**（在"定期报告"里），
   打开其中的三张表：**资产负债表**、**利润表**、**现金流量表**。
   —— 看不懂没关系，Week 2 讲过的三张表结构照着找就行。
3. 如果你更想看港股，换成 **港交所披露易** `www.hkexnews.hk`，
   搜关键词 **"债务重组"**、**"清盘呈请"**、**"内幕消息"**。

### 查什么

- 让它陷入麻烦的**那件事**是什么？（某个大客户跑了？某个项目亏了？
  借的钱到期还不上？替关联方担保出事了？）
- 它账上的**货币资金**有多少？**一年内到期的债务**有多少？
- 它最近一个完整年度的**经营活动现金流量净额**是正还是负？
- 公告里有没有出现"**银行账户被冻结**""**资产被查封**""**诉讼**"？
- 它现在的**总市值**是多少？它的**净资产**是多少？

### 回答这 5 个问题

1. 这家公司陷入困境的原因，属于本周讲的哪一类（经营问题 / 法律纠纷 / 债务太重）？
   有没有两类同时出现？
2. 用下面的公式算一下它的"现金跑道"：
   **现金跑道（季度）= 货币资金 除以 每个季度经营净流出的钱**。
   如果它的经营现金流是正的，就直接写"经营本身能产生现金"。
3. 假设它真的走到破产重整，**谁会第一个拿到钱**？谁的顺序排在最后？
   普通股股东大概能拿到什么？
4. 把它的总市值和净资产比一比，再和"清算价值"比一比
   （清算价值按 Week 9 学过的办法，把资产打折估算）。
   它的股价是在说"这家公司还值点钱"，还是在说"这家公司一定会死"？
5. 最后，也是最关键的一问：**这次分析之后，你愿意买吗？**
   如果你不愿意，请写下**至少三条**具体的、可以用数字或公告证明的理由。

### 判断标准（对答案用）

- **第 1 题**：三类原因经常是连锁的。**债务太重**往往是放大器：
  同样一笔亏损，没借钱的公司只是当年难看，借了很多钱的公司直接还不上利息。
  能把这条"放大器"说出来，就算过关。
- **第 2 题**：这一题的重点不是算出精确数字，而是**建立"跑道"这个概念**。
  一家公司账上有 20 亿元、每个季度净流出 3 亿元，跑道就是 6 个多季度；
  如果同时还有 8 亿元债务到期，跑道缩到 4 个季度。
  **跑道越短，公司越没有资格"等市场好转"。**
- **第 3 题**：顺序一般是：**有担保债权人 → 破产费用和共益债务 → 职工工资社保
  → 税款 → 普通无担保债权 → 优先股 → 普通股**。
  （具体顺序以现行《企业破产法》条文和那份重整计划为准。）
  普通股排在最末，绝大多数破产重整案里**拿到的是零**。
- **第 4 题**：这里没有标准答案。合格的答案是**能同时说出两边的理由**：
  一边是"市值已经远低于净资产，看起来便宜"；
  另一边是"净资产本身可能是假的——应收账款收不回来、存货卖不掉、
  商誉一文不值"。**能想到第二边，说明你真的读懂了这一周。**
- **第 5 题**：如果你写的是"因为它是 ST，所以不买"，这不算理由，
  那只是标签。合格的答案长这样：
  "① 它一年内到期的债务是账上现金的 3 倍，而经营现金流连续两年为负；
  ② 公告里已经出现银行账户被冻结，说明供应商和银行都在抢；
  ③ 我算不出它在任何一种结局下的回收值，因为我看不到它的资产明细。
  **看不懂，就是最充分的理由。**"

> 📌 **划重点：** 这道作业真正的目的，不是让你去买困境证券，
> 而是让你**养成一个顺序**：看任何一家公司，先问"万一出事我还剩什么"，
> 再问"它能赚多少"。这个顺序，是这一周最值钱的东西。
