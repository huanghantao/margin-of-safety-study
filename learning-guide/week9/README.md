## 为什么要有这一周

先看一个特别常见的场景。

你在股票软件里看到一家公司，股价 12 元。你打开某个财经网站，
上面写着"机构目标价 25 元"。你打开另一个，写着"合理估值 9 元"。
你再打开第三个，分析师说"对应明年 18 倍市盈率，目标价 31 元"。

三个数字，12 元、9 元、25 元、31 元。**谁对？**

一个从没学过估值的人，这时候只能三选一：相信喊得最响的那个，
或者相信最合自己心意的那个（你已经买了，所以你希望是 31 元）。

学完这一周，你会知道这几个人**可能都没说谎**，但他们的数字之所以差这么远，
是因为每个人用的**方法不同、假设不同**。你会知道：

- 估值的第一步不是"算出一个数"，而是"**决定用哪种方法**"；
- 每一种方法本身都只能给出一段**区间**，而不是一个点；
- 把几种方法的区间摆在一起，你会得到一个更宽的区间，
  而你要买的，是**大幅低于这个区间最低那一端**的价格。

这就是卡拉曼在《安全边际》第八章里做的事。他自己说得很清楚：

> "任何想精确评估企业价值的尝试都将带来不准确的评估。问题是人们很容易将作出精确预测的能力与作出正确预测的能力混为一谈。"（p131）

**精确不等于正确。** 这一周要训练的，就是抵抗"精确"的诱惑。

## 学完这一周，你会得到什么

- 你能说清楚**为什么估值永远给不出一个精确的数**，并且能用一个具体例子
  （专业分析师对同一项资产的预期差两倍）来说明这件事。
- 你能拿一张纸，把"未来每年 100 元、共 5 年、贴现率 10%"这类问题
  **一年一年除出来**，并列出完整的折现表格，不需要任何公式符号。
- 你能说出**预测未来现金流的三个难题**分别是什么，以及每一个难题该怎么用"保守"来对冲。
- 你能解释**贴现率不是利率、不是通胀率、不是 GDP 增速**，
  而是"这笔钱我要求一年赚回百分之几"，并且能说出为什么拿不准时要往高里放。
- 你能自己算一家公司的**清算价值**，并且知道为什么清算价值通常远低于账面价值。
- 你能看出"某某公司合理估值 XX 元"这句话里，**缺了哪三样东西**
  （用的哪种方法、假设是什么、是一段区间还是一个点）。
- 你能完整复述 Esco 电子公司这个案例：一家股价 3 美元、有形资产账面价值 25 美元、
  纯营运资金净额 15 美元的公司，四种方法各自算出什么数。
- 最后一条，也是最重要的一条：**你会得到一个可以反复使用的动作**——
  拿一张纸，把一家公司的价值算成"最低多少、最高多少"，
  然后规定自己只在价格低于最低那一段时才考虑买入。这就是这一周对你钱包的全部意义。

## 本周术语表（本周新出现的词）

| 词 | 一句话解释 |
|---|---|
| 价值范围 | 一家公司不是"值 20 元"，而是"大概值 18 到 26 元之间"。区间比点更接近真相 |
| 净现值法 / 现值分析法 | 把一家公司未来能产生的钱，一年一年折回今天，再加起来。英文缩写是 NPV |
| 现值 | 未来的某笔钱，相当于今天的多少钱 |
| 贴现率 | 把未来的钱折回今天时，你要求的那份年回报率。它回答"这笔钱放在这里，我要求一年赚百分之几" |
| 敏感度分析 | 把假设（现金流、贴现率）上下挪一挪，看算出来的价值会变多少。它是"这个结论稳不稳"的体检 |
| 终值 | 在现值分析里，预测期最后一年之后那"一整段未来"折算出来的价值。它常常占总价值的大头，也最不可靠 |
| 永续年金 | 每年都给你同样一笔钱、永远给下去。它今天的价值等于"每年的钱除以贴现率" |
| 私有市场价值法 | 不看股市，而是问：一个老练的商人愿意花多少钱把整家公司买下来 |
| 清算价值 | 公司今天就关门，把资产一件件卖掉、还完所有债之后，还能剩下多少 |
| 拆卖价值 | 清算价值的升级版：把每项资产分别卖给最需要它的人，按最高价算 |
| 纯营运资金净额 | 流动资产减流动负债，再减掉所有长期债务。格雷厄姆式的"最硬的底"（英文 net net） |
| 股市价值法 | 不比别的，就看同类公司在股市上卖多少钱，拿这个来估 |
| 反射关系 | 价格不只是反映价值，它还能反过来改变价值。股价太低会让公司真的融不到钱 |
| 自我实现的预言 | 大家都觉得它要垮，于是它真的垮了；大家都觉得它行，于是它真的行 |
| 商誉 | 公司收购别人时，付的价钱超出对方净资产的那一部分。会计上要分年摊销，但它不是真的花掉了现金 |
| 商誉摊销 | 把商誉分年"记账消耗掉"的动作。它会压低账面利润，但不减少现金 |
| 非经常性开支 | 一次性发生的费用（重组、遣散、合同赔偿）。它会让某一年的利润很难看，但不会年年发生 |
| 有序清算 / 低价甩卖 | 从容地一件件卖（卖得贵、但慢），对上急着变现（卖得快、但便宜） |

## 🔍 动手作业

这一周的作业只有一个目标：**把"看别人的估值结论"变成"自己走一遍流程"。**
你需要一支笔、一张纸。除了四则运算，不需要任何工具。

### 去哪里查

- **A 股公司**：巨潮资讯网（`cninfo.com.cn`）——输入公司代码或名字，
  在"公告"里找最近一期的**年度报告**。年报里你最需要的是三张表：
  **合并资产负债表**、**合并利润表**、**合并现金流量表**。
- **港股公司**：港交所披露易（`hkexnews.hk`）——在公司公告里找
  **Annual Report（年报）**。
- 如果你已经有习惯用的行情软件，也可以直接看它整理的"财务摘要"页面，
  但**至少核对一次原始年报的数字**，因为二手整理经常有口径差异。

### 查什么

从下面这个名单里挑**一家**你最好奇的公司
（贵州茅台 600519、长江电力 600900、福耀玻璃 600660、中国石油 601857、
腾讯控股 0700、招商银行 600036、中国神华 601088），然后做三件事：

1. 在资产负债表里找到这四个数字，抄成一行：
   **流动资产合计**、**流动负债合计**、**非流动负债合计**、**归母净资产**。
2. 在行情软件里找到它最新的**总市值**（不是股价，是总市值）。
3. 在利润表里找到**营业收入**和**归母净利润**。

### 回答这五个问题

1. **算一遍营运资金净额，再算一遍纯营运资金净额。**
   用"流动资产 - 流动负债 - 非流动负债"的口径（教学用的简化版）。
   步骤：先写流动资产，再减流动负债，再减非流动负债，每一步都写下中间结果。
2. **这家公司的总市值，比它的纯营运资金净额高还是低？**
   - 如果总市值**低于**纯营运资金净额：这是一家"净净股"，
     格雷厄姆最感兴趣的类型。请接着问一句：它为什么会这么便宜？
     （答案通常在这两种情况里：市场觉得它会持续亏损烧钱，或者它的流动资产本身有问题。）
   - 如果总市值**远远高于**纯营运资金净额：正常。
     把它记下来，说明这家公司的价值主要不来自资产，而来自**未来能赚的钱**——
     那你就必须用第 1 章和第 2 章的方法，去估它那些未来的钱。
3. **它的归母净资产是正还是负？**
   如果是负的，说明"账面价值"这条尺子对它完全失效，别再拿市净率说事了。
4. **用第 2 章的方法，给这家公司选一个贴现率，并写下你选它的理由。**
   写成一个句子，例如："我选 12%，因为它是强周期行业，盈利波动大，
   我对五年后的现金流没把握。"这一题没有标准答案，**但"理由"必须有**。
5. **假设一个最悲观的情景**：这家公司未来 10 年每年只给你 1 元（就写 1 元，不管实际数字），
   第 10 年之后什么都没有。贴现率用你第 4 题选的那个。
   把它的一年一年折现表列出来，算出这家公司在你最悲观假设下值多少钱。

### 判断标准（参考答案思路）

- 第 1 题：**纯营运资金净额 = 流动资产 - 流动负债 - 非流动负债**。
  注意这里用的是"全部负债"，不是只减短期债务——这是教学简化版，
  目的是让你得到一个"清算时大概能剩下多少"的粗估。如果你的结果是负数，
  说明这家公司靠变卖家当还不完债，它的股东权益几乎完全依赖"未来能赚钱"这一件事。
- 第 2 题：A 股里真正低于纯营运资金净额的公司**很少**，港股里多一些。
  找不到是很正常的——这本身就是"机会在哪里"这个话题的一部分。
- 第 4 题：没有唯一正确答案。常见的说法是：确定性高的（水电、高速公路）用 8%~10%；
  强周期的（煤炭、石油、航运、券商）用 12%~15%。**关键是你能说出为什么**，
  而不是背一个数字。
- 第 5 题：如果贴现率是 10%，10 年每年 1 元折回今天 = 6.14 元；
  如果用 12%，则是 5.65 元。这两个数字你应该能和下面的表对上：

| 年数 | 每年 1 元，10% 折现 | 每年 1 元，12% 折现 |
|---|---|---|
| 第 1 年 | 0.91 | 0.89 |
| 第 2 年 | 0.83 | 0.80 |
| 第 3 年 | 0.75 | 0.71 |
| 第 4 年 | 0.68 | 0.64 |
| 第 5 年 | 0.62 | 0.57 |
| 第 6 年 | 0.56 | 0.51 |
| 第 7 年 | 0.51 | 0.45 |
| 第 8 年 | 0.47 | 0.40 |
| 第 9 年 | 0.42 | 0.36 |
| 第 10 年 | 0.39 | 0.32 |
| **合计** | **6.14** | **5.65** |

**做完这一份作业，你就已经把这一周最重要的那个动作走完一遍了。**
