> 这是 Week 8。上周（Week 7）我们把整本书最重要的一句话立了起来：
> **投资的第一目标不是赚钱，是别亏钱**；而做到这一点的工具，是安全边际。
> 这一周我们要回答一个更靠前的问题：**你脑子里那套"投资该怎么想"的地基，

---

## 为什么要有这一周

先看一个真实生活里天天发生的场景。

你的朋友小李兴冲冲地跟你说："我今年赚了！我买的那只基金跑赢沪深 300 五个点！"
你替他高兴，接着问了一句："那你账户里现在是多了还是少了？"
他愣了一下："少了……我亏了 20%，但指数跌了 25% 啊。"

问题来了：**小李这一年，到底算成功还是失败？**

不同的人会给你完全相反的答案：

- 基金销售说：成功。跑赢基准 5 个百分点，同类排名靠前。
- 你的钱包说：失败。100 元变成 80 元。
- 卡拉曼会说：你把两块完全不同的记分牌搞混了——**相对表现不是你的钱，绝对表现才是。**

这一周要做的，就是把"投资的地基"这三根柱子一根一根立起来：

1. **自下而上**：不预测经济、不预测大盘，一家公司一家公司地看（第 0 章）。
2. **绝对表现**：只跟自己的目标比，不跟指数比（第 1 章）。
3. **风险规避**：把"别亏钱"当成一件需要用方法去解决的事，而不是一句口号（第 2、3、4、5 章）。

## 学完这一周，你会得到什么

- 你能分清**"我跑赢了吗"和"我的钱变多了吗"**这两个问题，并且知道哪一个才是你的目标。
- 你能指出"高风险一定高回报"这句话错在哪里，并且能用一个具体例子反驳它。
- 你能把一家公司的下跌分成三类：**只是价格波动、需要观察的周期低谷、价值被永久损坏**，
  并说出每一类你该做什么。
- 你能用大白话向别人解释 Beta 是什么，以及它为什么衡量不了"会不会真的亏钱"。
- 你能算出"每年投一笔钱、中间跌一半"的情况下，你的最终收益为什么会比"一路上涨"还高，
  并且知道这个结论**必须**附加什么前提。
- 最后一条，也是最重要的一条：**你会知道哪些钱可以放进股市、哪些钱绝对不行**——
  因为这一周讲的所有风险，最后都落在"你会不会被迫在低点卖出"这一件事上。

## 本周术语表（本周新出现的词，以及需要复习的旧词）

| 词 | 一句话解释 |
|---|---|
| 自上而下 | 先预测整个经济、利率、大盘的走向，再倒推出该买什么。像先预测"今年全国天气"再决定带哪把伞 |
| 自下而上 | 不预测大环境，一家公司一家公司地研究：它值多少钱？现在的价格比它低多少？ |
| 基本面分析 | 通过研究一家公司的生意本身（赚多少钱、欠多少债、竞争对手是谁）来判断它值多少钱，而不是看股价走势图 |
| 相对表现 | 跟别人（通常是指数或其他投资者）比出来的成绩 |
| 绝对表现 | 只跟自己比：我的钱是变多了还是变少了 |
| 业绩比较基准 | 衡量成绩用的那把尺子，比如"沪深 300 指数"。基金合同里会写明 |
| Beta 值 | 用过去的价格数据算出来的一个数：大盘涨跌 1%，这只证券平均涨跌百分之几 |
| 波动 | 价格上下起伏的幅度。注意：波动和"会不会亏钱"是两件事，这是本周的核心 |
| 永久性损失 | 亏掉的钱再也回不来了（公司价值真的没了、或你被迫在低点卖出），与"账面浮亏"相对 |
| 机会成本 | 因为把钱占在别处，而错过未来更好的机会所损失的东西。注意它和"手续费"完全不是一回事（Week 5 已学过，本周直接使用） |
| 现金 | 你随时能用的钱。在价值投资里它不是"闲置"，而是等着捡便宜货的弹药 |
| 对冲 | 同时持有两样价格大概率反向变动的东西，用一边的赚来缓冲另一边的亏（第 5 章只讲概念） |

## 🔍 动手作业

这一周的作业，是**亲手算一遍"相对表现"和"绝对表现"的区别**。不用开户，不用花钱，
只要会查资料、会用计算器。

### 去哪里查

1. **中证指数有限公司官网** `www.csindex.com.cn` → 指数专区 → 搜"沪深 300"→
   看它的"历史行情"或"指数月报"（也可以查上证指数、中证 500）。
2. **巨潮资讯网** `www.cninfo.com.cn`（中国证监会指定的信息披露网站）→ 搜一只
   跟踪沪深 300 的指数基金（例如名字里带"沪深 300"的 ETF 或指数基金）→ 找到它的
   **基金年度报告** → 里面有一节叫"基金净值表现"，会列出每年的净值增长率。
3. 如果你更关心港股，可以换成 **港交所披露易** `www.hkexnews.hk`，查一只跟踪
   恒生指数的 ETF 的年报。

### 查什么

最近 **3 个完整年度**（例如 2022、2023、2024，具体看你查的时候哪几年已经结束）：

- 沪深 300 指数这三年的**年度涨跌幅**；
- 那只基金这三年的**年度净值增长率**。

### 回答这 5 个问题

1. 三年里，这只基金每一年分别跑赢还是跑输了指数？差几个百分点？
2. 把三年连起来算（每年的变化率**连着乘**，例如先涨 10% 再跌 20%，
   就是 1.10 乘以 0.80 等于 0.88），基金三年的累计回报是多少？指数呢？
3. 这三年里，有没有哪一年基金的**绝对回报是负的**？那一年它是跑赢还是跑输？
4. 如果只看"跑赢还是跑输"，你给这只基金打几分？如果只看"我投入的钱最后变成多少"，
   你给它打几分？
5. 基金的年报里会写明管理费率（例如每年 0.5%）。如果一只基金每年比指数多收 0.5%
   的费用，十年下来大约会少掉多少？（提示：0.5% 连着扣十年，用 0.995 乘十次，
   算个大概即可。）

### 判断标准（对答案用）

- **第 1、2 题**：只要你能分清"两个百分点的差"和"两个百分点的乘法"，就算过关。
  最常见的错误是把三年的涨跌幅直接相加——**涨跌幅不能直接相加，必须连着乘**。
  先跌 50% 再涨 50%，不是回到原点，而是只剩 75%。
- **第 3 题**：这一题就是本周的全部要点。**跑赢一个下跌的指数，你的钱还是少了。**
- **第 4 题**：参考答案是"两块记分牌都要看，但只有第二块能花"。
  只看相对表现，你会因为"大家都亏得比我多"而心安理得；
  只看绝对表现，你又会失去一个有用的自检工具（长期持续跑输指数，
  说明你的方法可能真的有问题）。
- **第 5 题**：0.995 连乘十次大约是 0.951，也就是**十年少掉约 5%**。
  这个数字单看不大，但如果一只基金每年比指数多收 1.5%，
  十年下来就是大约 14%——这就是"费率侵蚀收益"的算法。
